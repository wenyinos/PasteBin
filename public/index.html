内容在你的浏览器中加密后才上传，服务器无法读取。分享链接会附带解密密钥（# 之后的部分），请勿提交到公开渠道。

API Token

用于命令行或脚本调用本站 API。Token 只在创建时显示一次，且不随统一认证登出而失效—— 如怀疑泄漏请立即撤销。

请立即复制保存，此明文只显示这一次：
命令行用法 
# 创建 paste，返回 short_code
curl -s -X POST https://<站点>/api/pastes \
  -H "Authorization: Bearer paste_你的Token" \
  -H 'Content-Type: application/json' \
  -d '{"content":"hello","language":"bash"}' | jq -r .short_code

# 读取原始内容
curl https://<站点>/raw/<short_code>
